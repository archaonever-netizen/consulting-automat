# Быстрый старт: Задачи + ИИ-Чат

## 30 секунд до первого использования

### 1️⃣ Установить пакеты
```bash
pip install -r requirements.txt
```

### 2️⃣ Инициализировать БД
```bash
python -c "
from app import app, db
with app.app_context():
    db.create_all()
    print('✅ База данных инициализирована!')
"
```

### 3️⃣ Запустить приложение
```bash
python app.py
```

**Готово! Приложение доступно на http://localhost:5000**

## Использование без Яндекс.Календаря

Если не нужна синхронизация с календарём, достаточно просто запустить приложение выше.

## Использование с Яндекс.Календарём (опционально)

### A. Подготовить OAuth
1. Перейти на https://oauth.yandex.ru/client/new
2. Создать приложение (Web-app)
3. Скопировать Client ID и Secret
4. Добавить Redirect URI: `http://localhost:5055/auth/yandex/callback`

### B. Создать `.env.local`
```
YANDEX_CLIENT_ID=ваш_id
YANDEX_CLIENT_SECRET=ваш_secret
YANDEX_REDIRECT_URI=http://localhost:5055/auth/yandex/callback
PROMPTRA_API_KEY=ваш_api_key
```

### C. Подключить календарь в приложении
1. Открыть раздел **Задачи**
2. Нажать кнопку **Подключить Яндекс.Календарь**
3. Авторизоваться в Яндексе
4. Готово! Теперь все задачи будут синхронизироваться автоматически

## Первые тесты

### ✅ Тест 1: Создать задачу
1. Открыть **Задачи** → **+ Новая задача**
2. Заполнить:
   - Название: "Позвонить клиенту"
   - Клиент: выбрать любого
3. Нажать **Создать задачу**
4. ✅ Задача должна появиться в списке

### ✅ Тест 2: AI Task Manager
1. Создать задачу только с названием и клиентом
2. Нажать **✓ Выполнить**
3. Заполнить хотя бы поле "Фактический результат"
4. Нажать **Завершить и сохранить**
5. ✅ Должен открыться чат с ИИ-вопросами о незаполненных полях
6. Ответить на 1-2 вопроса
7. ✅ Поля должны автоматически заполниться в задаче

### ✅ Тест 3: ИИ-Чат
1. Открыть **Чаты с ИИ** → **+ Новый чат**
2. Написать сообщение: "Какие риски в расширении в новый регион?"
3. Нажать **Отправить**
4. ✅ Получить ответ от ИИ через 3-5 секунд

### ✅ Тест 4: Яндекс.Календарь (если подключён)
1. Создать задачу с временем и длительностью
2. Открыть Яндекс.Календарь в новой вкладке
3. ✅ Событие должно появиться в календаре

## Структура для быстрого понимания

```
📊 ЗАДАЧИ
├─ Список задач (левая колонка)
│  └─ Карточка задачи
│     └─ Поля: название, клиент, время, статус
│     └─ Кнопки: ▶ Старт, ✓ Выполнить
│
├─ Детали задачи (правая колонка)
│  └─ Полная информация о выбранной задаче
│
└─ 📅 При выполнении с пустыми полями
   └─ Открывается чат с ИИ (AI Task Manager)
      └─ ИИ задаёт вопросы
      └─ Заполняет поля автоматически
      └─ Возвращает в Задачи

💬 ИИ-ЧАТ
├─ Список сессий (левая колонка)
│  └─ Каждая сессия с иконкой и временем
│
└─ Активный чат (правая колонка)
   ├─ История сообщений
   ├─ Ввод сообщения
   └─ Ответ от ИИ (qwen/qwen3-max)

📅 ЯНДЕКС.КАЛЕНДАРЬ (опционально)
├─ OAuth подключение один раз
└─ Автоматическая синхронизация событий
   └─ Название задачи + описание с деталями
```

## Команды для разработчика

### Посмотреть созданные задачи
```python
from app import app, db
from models import UserTask

with app.app_context():
    tasks = UserTask.query.all()
    for t in tasks:
        print(f"- {t.title} ({t.status})")
```

### Очистить все задачи (только разработка!)
```python
from app import app, db
from models import UserTask, UserChatSession, UserChatMessage

with app.app_context():
    UserChatMessage.query.delete()
    UserChatSession.query.delete()
    UserTask.query.delete()
    db.session.commit()
    print("✅ Все данные удалены")
```

## Часто задаваемые вопросы

**Q: Почему не работает Яндекс.Календарь?**  
A: Нужно подключить его в интерфейсе (кнопка на странице Задач) или установить переменные окружения.

**Q: Как отключить ИИ?**  
A: Просто не заполняйте все обязательные поля при завершении задачи — чат не появится.

**Q: Может ли два пользователя видеть одинаковые задачи?**  
A: Нет, каждый пользователь видит только свои задачи (созданные им).

**Q: Где хранятся сообщения чата?**  
A: В таблице `user_chat_messages` в БД. Они сохраняются навсегда (пока вы не удалите сессию).

**Q: Можно ли использовать Google Calendar вместо Яндекса?**  
A: Сейчас реализован только Яндекс. Google Calendar можно добавить потом.

## Если что-то не работает

1. **Проверить консоль** — обычно там есть информация об ошибке
2. **Проверить логи** — `[ERROR]`, `[LLM error]` и т.д.
3. **Обновить зависимости** — `pip install --upgrade -r requirements.txt`
4. **Удалить и пересоздать БД**:
   ```bash
   rm instance/app.db  # если SQLite
   python -c "from app import app, db; app.app_context().push(); db.create_all()"
   ```
5. **Проверить `.env.local`** — переменные окружения установлены?
