# Интеграция Яндекс.Календаря в ШЕФ

## Что это даёт

Когда пользователь создаёт задачу в системе ШЕФ:
1. **Событие автоматически добавляется в Яндекс.Календарь** с названием, временем начала, длительностью и полным описанием
2. При выполнении задачи с незаполненными полями **ИИ-менеджер автоматически заполняет поля через чат**
3. События синхронизированы через CalDAV (открытый стандарт)

## Подготовка к использованию

### Шаг 1: Создать приложение в Яндексе

1. Перейти на https://oauth.yandex.ru
2. Нажать «Создать приложение» (или войти в личный кабинет)
3. Выбрать тип приложения: **Web-приложение**
4. Указать:
   - **Название**: ШЕФ Task Manager
   - **Платформы**: Web
   - **Права доступа**: `calendar:api` (полный доступ к календарю)
5. Нажать **Создать приложение**
6. В открывшемся окне скопировать:
   - **ID приложения** (Client ID)
   - **Пароль приложения** (Client Secret)

### Шаг 2: Указать Redirect URI

1. В настройках приложения добавить **Redirect URI**:
   ```
   http://localhost:5055/auth/yandex/callback
   ```
   (или ваш домен в production, например: `https://your-domain.com/auth/yandex/callback`)

2. Сохранить настройки

### Шаг 3: Добавить переменные окружения

Создать файл `.env.local` в корне проекта (или обновить существующий):

```
YANDEX_CLIENT_ID=123456789
YANDEX_CLIENT_SECRET=your_secret_key_here
YANDEX_REDIRECT_URI=http://localhost:5055/auth/yandex/callback
```

Заменить значения на реальные из Яндекса.

## Использование

### Для пользователей

1. **Подключить календарь** (первый раз при использовании):
   - Перейти в **Задачи** → кнопка **Подключить Яндекс.Календарь**
   - Войти в аккаунт Яндекса и разрешить доступ
   - После этого все задачи будут автоматически синхронизированы

2. **Создать задачу**:
   - Раздел **Задачи** → **+ Новая задача**
   - Заполнить название и выбрать клиента (остальное опционально)
   - При сохранении задача автоматически появится в Яндекс.Календаре

3. **Выполнить задачу**:
   - Нажать **▶ Старт** чтобы начать
   - Нажать **✓ Выполнить** чтобы закрыть
   - Заполнить результаты выполнения
   - Если есть незаполненные поля → появится чат с ИИ-менеджером
   - Ответить на вопросы ИИ → поля заполнятся автоматически

### Для разработчиков

#### API маршруты

**Яндекс OAuth:**
- `GET /auth/yandex` — Начать OAuth поток
- `GET /auth/yandex/callback` — Callback от Яндекса

**Задачи:**
- `GET /tasks` — Список задач пользователя
- `POST /tasks/create` — Создать новую задачу + добавить в календарь
- `GET /tasks/<id>` — Получить данные задачи (JSON)
- `POST /tasks/<id>/start` — Начать выполнение (изменить статус)
- `POST /tasks/<id>/complete` — Завершить задачу (сохранить результат, проверить незаполненные поля)
- `POST /tasks/<id>/delete` — Удалить задачу из системы и календаря

**ИИ-Чат:**
- `GET /chat` — Список чат-сессий или открыть конкретный чат
- `POST /chat/session/new` — Создать новую сессию
- `POST /chat/<session_id>/send` — Отправить сообщение, получить ответ AI

#### Схема БД

Добавлены модели:
- `UserTask` — Пользовательская задача
- `TaskCompletion` — Результаты выполнения задачи
- `UserChatSession` — Сессия чата пользователя
- `UserChatMessage` — Сообщение в чате

Добавлены поля к `User`:
- `yandex_calendar_token` — OAuth токен доступа
- `yandex_calendar_refresh_token` — Токен для обновления
- `yandex_calendar_token_expiry` — Время истечения токена
- `yandex_login` — Логин пользователя в Яндексе (для CalDAV)

#### Модуль Яндекс.Календаря

Файл `yandex_calendar.py` содержит функции:

```python
get_oauth_url()
# Получить URL для редиректа на Яндекс OAuth

exchange_code(code)
# Обменять код на токен доступа

create_event(user, task)
# Создать событие в календаре и вернуть UID

delete_event(user, event_uid)
# Удалить событие из календаря

refresh_token_if_needed(user)
# Обновить токен доступа если истёк
```

## Проблемы и решения

### "Ошибка при подключении календаря: ..."

1. Проверить что переменные окружения установлены корректно
2. Убедиться что Redirect URI совпадает в коде и в настройках Яндекса
3. Проверить что токены не истекли (их время жизни обычно 1 год)

### Событие не появилось в календаре

1. Убедиться что токен валиден (он автоматически обновляется)
2. Проверить что `yandex_login` заполнен в БД (он заполняется при OAuth)
3. Проверить логи приложения на ошибки CalDAV

### Не работает AI Task Manager

1. Убедиться что установлена правильная модель qwen: `qwen/qwen3-max`
2. Проверить что `PROMPTRA_API_KEY` установлен и валиден
3. Проверить логи: `[LLM error: ...]`

## Безопасность

- Токены хранятся зашифрованными в БД
- Каждый пользователь может подключить только свой Яндекс аккаунт
- События создаются в личном календаре пользователя
- Все API маршруты защищены проверкой `@login_required`
