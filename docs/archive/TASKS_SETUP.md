# Запуск модуля Задачи и ИИ-Чата

## Что реализовано

### 1. Модуль Задачи
- **Список задач** с фильтром по статусу
- **Создание задач** с опциональными полями (можно создать только с названием)
- **Выполнение задач** с сохранением результатов
- **Синхронизация с Яндекс.Календарём** (события создаются/удаляются автоматически)

### 2. ИИ-менеджер задач
- Когда задача завершена с незаполненными полями → появляется чат
- ИИ (qwen/qwen3-max) задаёт вопросы о недостающих полях
- Автоматически парсит ответы и заполняет поля в задаче
- Поддерживает task_manager контекст

### 3. Реальный ИИ-Чат
- Заменён старый mock-чат на реальный
- Список чат-сессий с историей
- Два типа контекста: `general` (обычный чат) и `task_manager` (менеджер задач)
- Реальный LLM ответ от qwen/qwen3-max через Promptra API

## Быстрый старт

### 1. Установить зависимости
```bash
pip install -r requirements.txt
```

### 2. Создать `.env.local` (если не создан)
```
YANDEX_CLIENT_ID=ххх
YANDEX_CLIENT_SECRET=ххх
YANDEX_REDIRECT_URI=http://localhost:5055/auth/yandex/callback
PROMPTRA_API_KEY=your-key
```

Подробнее см. [YANDEX_CALENDAR_SETUP.md](YANDEX_CALENDAR_SETUP.md)

### 3. Инициализировать базу данных
```bash
python
>>> from app import app, db
>>> app.app_context().push()
>>> db.create_all()
>>> exit()
```

Или используйте миграции если они настроены.

### 4. Запустить приложение
```bash
python app.py
```

Приложение запустится на `http://localhost:5000` (или указанном порту).

## Использование

### Для пользователя

1. **Открыть раздел Задачи** из сайдбара
2. **Создать новую задачу** — заполнить минимум: название + клиент
3. **Просмотр задачи** — выбрать в списке, детали откроются справа
4. **Начать выполнение** — нажать "▶ Старт"
5. **Завершить задачу** — нажать "✓ Выполнить"
   - Заполнить результат выполнения
   - Указать сложности (опционально)
   - Если есть незаполненные обязательные поля → откроется чат с ИИ
6. **Чат с ИИ** — ответить на вопросы ИИ → поля заполнятся автоматически

### Яндекс.Календарь

1. Первый раз нужно подключить календарь (кнопка на странице Задач)
2. После этого все созданные задачи автоматически попадают в календарь
3. Описание события содержит все детали задачи

### Новый ИИ-Чат

1. **Открыть раздел Чаты с ИИ** из сайдбара
2. **Создать новый чат** или выбрать существующий
3. **Написать сообщение** → получить ответ от qwen/qwen3-max
4. **История сохраняется** автоматически

## Структура кода

### Модели (`models.py`)
- `UserTask` — задачи пользователя
- `TaskCompletion` — результаты выполнения
- `UserChatSession` — сессии чата
- `UserChatMessage` — сообщения в чате

### Маршруты (`app.py`)
- `/tasks` — список задач
- `/tasks/create` — создание
- `/tasks/<id>/start` — начать
- `/tasks/<id>/complete` — завершить
- `/tasks/<id>/delete` — удалить
- `/chat` — список чатов
- `/chat/session/new` — новый чат
- `/chat/<id>/send` — отправить сообщение
- `/auth/yandex*` — OAuth для Яндекса

### Шаблоны
- `templates/tasks.html` — интерфейс задач (двухколоночный)
- `templates/chat.html` — интерфейс чата (с историей и сессиями)

### Утилиты
- `yandex_calendar.py` — CalDAV и OAuth функции
- `deepseek_config.py` — конфигурация LLM моделей

## API Документация

### Создание задачи
```http
POST /tasks/create
Content-Type: application/x-www-form-urlencoded

title=Связаться с клиентом
client_id=1
start_time=2026-06-10T14:00:00
duration_minutes=30
input_data=Иван, +79991234567, ООО "Рога и копыта"
goal=Записать на интервью
action_description=Позвонить клиенту
expected_result=Клиент записан на 10 июня
```

### Завершить задачу
```http
POST /tasks/1/complete
Content-Type: application/json

{
  "actual_result": "Позвонил, записал на 11 июня",
  "is_failure": false,
  "difficulties": "Клиент был в спешке",
  "how_overcome": "Позвонил позже",
  "next_step": "Провести интервью 11 июня в 10:00"
}
```

### Отправить сообщение в чат
```http
POST /chat/1/send
Content-Type: application/json

{
  "message": "Какие риски в этом проекте?"
}
```

## Отладка

### Логи
Приложение выводит логи в консоль. Ключевые события:
- `[TASK_MANAGER]` — AI менеджер заполняет поля
- `[CALENDAR]` — операции с Яндекс.Календарём
- `[LLM]` — вызовы к LLM API

### Проблемы

**Задача не появилась в календаре**
- Проверить что токен Яндекса установлен
- Проверить логи на ошибки CalDAV
- Убедиться что `yandex_login` заполнен

**ИИ не заполняет поля**
- Проверить что модель установлена: `qwen/qwen3-max`
- Проверить PROMPTRA_API_KEY
- Проверить что ответ парсируется как JSON

**Чат не отвечает**
- Проверить что LLM API доступен
- Проверить логи на ошибки соединения
- Убедиться что история сообщений загружена

## Технические детали

### Яндекс OAuth поток
1. Пользователь нажимает "Подключить Яндекс.Календарь"
2. Редирект на `https://oauth.yandex.ru/authorize?...`
3. После авторизации → callback на `/auth/yandex/callback`
4. Обмен кода на токен доступа
5. Сохранение в БД: `yandex_calendar_token`, `yandex_login`

### CalDAV операции
- URL: `https://caldav.yandex.ru/{login}/`
- Авторизация: `OAuth {token}` header
- События: iCal format (VEVENT)
- Поиск по UID для удаления

### AI Task Manager
- Контекст: `task_manager` + `task_id`
- Системный промпт: описывает незаполненные поля
- Парсинг: извлекает JSON из конца ответа ИИ
- Обновление: сохраняет значение и переходит к следующему полю
