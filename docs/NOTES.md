## 2. Незавершённый перенос: Яндекс.Календарь ⚠️

Во Flask-версии была **полная** интеграция с Яндекс.Календарём (OAuth + CalDAV:
создание/удаление событий при создании/удалении задач, обновление токенов).
**В FastAPI-версию интеграция НЕ перенесена.** Что осталось:
- `yandex_calendar.py` в корне — рабочий модуль CalDAV+OAuth (без привязки к новому бэкенду);
- поля токенов в `backend/models.py:36-39` (User) и настройки в `backend/core/config.py:55-58`
  с пометкой «kept for future»;
- инструкции по настройке OAuth: перенесены в `docs/archive/YANDEX_CALENDAR_SETUP.md`
  и `docs/archive/TASKS_SETUP.md`.

Чтобы возродить: создать OAuth-приложение на https://oauth.yandex.ru/client/new (Web-app),
задать YANDEX_CLIENT_ID/SECRET/REDIRECT_URI, переписать `yandex_calendar.py` на async
и подключить к `backend/services/tasks.py`. Прод-требования из старого чеклиста: HTTPS
для OAuth callback, шифрование токенов в БД (по аналогии с Kaiten-токеном — Fernet).

## 3. Дизайн-система ШЕФ (выжимка из design_handoff_shef, папка удалена 12.06.2026)

Дизайн уже полностью портирован в `frontend/src/styles/styles.css` (память: этапы
редизайна 0–6 завершены). Полный референс (HTML-спека, redesign.css, guide.css, views.css,
logo.js, JSX-образцы) — в git-истории до коммита удаления.

Ключевые принципы (могут пригодиться при доработке UI):
- Тон: «спокойный шеф-стратег» — без эмодзи/капса/восклицаний; короткие фразы,
  конкретные числа, один следующий шаг.
- Один синий акцент: `--accent: #2563EB`, hover `#1D4ED8`; синий не перекрашивать.
- Мотив 45°: наклон акцента строго 45° (срезы аватаров, наконечник «Е» логотипа).
- Токены: фон `#FFFFFF`, текст `#1C1C1E`/`#6E6E76`, рамки `rgba(60,60,67,.08)`,
  радиусы 11/14/22px, статусные пилюли green `#1F9D57` / amber `#C2820F` / red `#E23D32`
  (+ weak-подложки), `--r-pill: 999px`.
- Типографика: заголовки Manrope 800 (трекинг −.035em), текст Inter 400–600;
  шкала: h1 28–34 / h2 24 / текст 14 / eyebrow 11.5 caps.
- Анимации: `cubic-bezier(.22,1,.36,1)`, transition `.2s cubic-bezier(.32,.72,0,1)`,
  уважать `prefers-reduced-motion`.
- Логотип: вордмарк SHEF_LOGO (viewBox `0 -18 720 236`), монограмма SHEF_MONO («Ш»
  с синим вымпелом) — favicon и «лицо» ИИ; зона защиты ≥ высоты «Ш».
