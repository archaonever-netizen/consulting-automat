## B. Решения, которые нужно принять ПЕРЕД стартом

Спроси пользователя (или выбери дефолт), это определяет объём:

1. **Технология фронтенда.**
   - **(дефолт) Остаёмся на Flask + Jinja** — каждый экран = шаблон, общий CSS уже есть (`integration/styles.css`), интерактив на ванильном JS + `fetch` (как автосейв анкет). Минимум новой инфраструктуры.
   - Альтернатива: вынести фронт в React (как в прототипе) + Flask как API. Дороже, нужен сборщик. Брать только если планируется большой SPA.

2. **Чат с ИИ и «сводка ШЕФ» — это реальный ИИ или пока UI-заглушка?**
   - **(дефолт) UI + заглушечные ответы** (моки из `redesign/data.js`), поле ввода работает, ответы предзаписаны/правилами. Без интеграции LLM.
   - Реальный ИИ: нужен ключ API и серверный прокси-роут. Делать отдельным этапом после UI.

3. **Health-скор / метрики клиента** — откуда брать?
   - **(дефолт)** Вычислять из имеющихся данных (например, % заполненности анкет = прогресс; кол-во анкет «Заполнено»). Никаких новых полей.
   - Или добавить поля в модель (revenue, риск и т.д.) — отдельный этап с миграцией БД.

> Дефолты выбраны так, чтобы получить **весь визуальный редизайн без новой тяжёлой логики**. ИИ и расширенные метрики — отдельными этапами поверх.

## C. Поэтапный план (порядок реализации)

### Этап 0 — База (быстро)
- Заменить `static/css/styles.css` на `integration/styles.css`.
- Заменить splash-SVG в `templates/base.html` (`integration/base_splash_snippet.html`), обновить строку Google Fonts (добавить `Inter ...;700`).
- Заменить `templates/index.html` на `integration/templates/index.html`.
- ✅ Результат: текущие страницы в новом дизайне.

### Этап 1 — Оболочка + сайдбар
- Создать layout с боковой навигацией (десктоп) → нижний таб-бар на узких экранах.
  Пункты: Главная, Чаты с ИИ, Клиенты, Аналитика, Задачи, Шаблоны, База знаний, Настройки.
  Внизу — карточка пользователя + промо.
- Источник разметки/классов: `redesign/Sidebar.jsx` + `.sidebar*` в `redesign/redesign.css`.
- В Jinja: вынести сайдбар в `templates/_sidebar.html`, включать через `{% include %}`; активный пункт — по текущему роуту. Контент страниц — в `.main`.
- Адаптив сайдбар→таб-бар: медиазапросы уже есть в `redesign/home.css` (`@media max-width:820px`).

### Этап 2 — Главная (`/`)
- Новый роут «Главная» (текущий список клиентов переедет на `/clients`).
- Блоки (см. `HomeView.jsx` + `home.css`): hero со сводкой ШЕФ (монограмма + текст), **ask-bar** с чипами, «Сегодня в фокусе» (фокус-лист), resume-карточки, pulse-строка.
- Данные: приветствие по времени суток; сводка — по агрегатам (клиенты, незаполненные анкеты); «в фокусе» — клиенты с незавершёнными анкетами. Заглушки текста — из `redesign/data.js`.

### Этап 3 — Клиенты (`/clients`)
- Грид (готов в `integration/templates/index.html` — перенести сюда) + **таблица** (toggle грид/таблица).
- Статс-полоса сверху (4 метрики), поиск, сегменты-фильтры.
- Health/спарклайн — по решению 3 (дефолт: прогресс заполнения анкет).
- Разметка: `ClientsList.jsx` + `.clients-grid/.clients-table` в `views.css`.

### Этап 4 — Карточка клиента (`/client/<id>`)
- Шапка (большой аватар-срез, имя, действия) + вкладки (Обзор/Бриф/Активность) + грид секций.
- AI-секции («Главные проблемы», «Рекомендуемые шаги») с **ШЕФ-байлайном**; метрики, чек-листы шагов.
- Сейчас `/client/<id>` ведёт на список анкет — его переименовать (например `/client/<id>/briefs`) или встроить анкеты во вкладку «Бриф».
- Разметка: `ClientDetail.jsx` + `views.css`.

### Этап 5 — Чаты с ИИ (`/chat`)
- Список сообщений, composer, состояние «думает» (скан монограммы), быстрые чипы.
- По решению 2: дефолт — моки/правила; ответы рендерятся как `.msg.ai`.
- Разметка: `ChatHome.jsx` + `views.css`. Хранение: новая модель `Message` (опц.) или сессия.

### Этап 6 — Заглушки разделов
- Аналитика / Задачи / Шаблоны / База знаний — экраны `empty-tab` (иконка + заголовок + подзаголовок), чтобы навигация была целостной. Наполнять позже.

## D. Принципы для всех экранов (не отступать)
- Дизайн-токены и компоненты — из `integration/styles.css` / `redesign/redesign.css`. Новые значения не выдумывать.
- Мотив 45°: аватары-срезы, синий слэш, монограмма со сканом «думает», диагональный въезд сообщений ИИ.
- Монограмма ШЕФ — везде, где «говорит» ИИ. Авторство подписано монограммой.
- Тон: коротко, по делу, без эмодзи/капса. Анимации мягкие, уважать `prefers-reduced-motion`.
- Бизнес-логику и данные не ломать; новые роуты не должны рушить существующие (анкеты, PDF, автосейв).
