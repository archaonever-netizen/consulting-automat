# Хендофф: внедрение дизайна ШЕФ в `consulting-automat` (Flask)

> Репозиторий: `archaonever-netizen/consulting-automat` — Flask + SQLAlchemy + Jinja2,
> серверный рендер, один `static/css/styles.css`, ванильный JS. **React не используется.**
> Цель: «надеть» дизайн-систему ШЕФ на существующее приложение **с минимальными правками шаблонов.**

---

## 0. Стратегия (читать первым)

Приложение уже размечено классами `.card`, `.btn`, `.btn-primary`, `.badge`, `.page-title`,
`.form-input`, `.modal-card`, `.toast` и т.д. Поэтому самый дешёвый и точный путь:

1. **Переписать `static/css/styles.css`** под токены и компоненты редизайна, **сохранив все имена классов.** Тогда весь интерфейс мгновенно «переоденется» почти без правок HTML.
2. **Заменить SVG-логотип в splash** (`templates/base.html`) на точный вордмарк «Концепция 1» (раздел 4).
3. Точечно усилить шаблоны мотивом 45° (аватары-срезы на карточках клиентов, ШЕФ-байлайны на статусах). Раздел 6.

Файлы-референс рядом (`ШЕФ - Дизайн-система.html`, `redesign/*.css`, `redesign/logo.js`) — **источник истины по значениям.** `.jsx`-файлы — только визуальный образец композиции; механику React игнорировать, мы на Jinja.

**Промпт для Claude Code:**

Шаблоны и роуты по возможности не меняй — только классы/разметку представления. После — раздел 6 точечно.»

**Фиделити:** high. Значения финальные, см. раздел 3.

## 2. Принципы и тон

Спокойный шеф-стратег: точность с источником, спокойная скорость (мягкие анимации), геометрия как голос, один синий акцент скупо, белый воздух (разделение тенью и волосяной линией). В продукте — без эмодзи, капса и восклицаний; короткие фразы, конкретные числа, один следующий шаг.

> ⚠️ В текущем `index.html` в кнопках есть эмодзи `✎` и `🗑`. По гайду их лучше заменить на line-иконки (карандаш / корзина) — см. `redesign/icons.jsx` (`edit`, `trash`).

### 3.3 Типографика
Сейчас у тебя **Manrope (заголовки) + Inter (текст)** — это можно оставить, ШЕФ-гайд допускает Manrope везде, но Inter в тексте читается хорошо. Решение:
- **Заголовки** (`h1–4`, `.page-title`, `.modal-title`) — Manrope **800**, трекинг `−.035…−.04em` (уже так).
- **Текст** — оставить Inter 400–600 (или перейти на Manrope 400–600 ради «одношрифтовости» — на твоё усмотрение; если меняешь, обнови `@import` в `base.html`).
- Базовый `line-height` тела можно ужать с `1.65` до `1.55` — у ШЕФ плотнее.

Шкала (desktop): hero 44–56 / h1 28–34 / h2 24 / лид 17–19 / текст 14 / eyebrow 11.5 (800, .14em, UPPERCASE).

### 3.4 Анимация
- Вход: `fadeInUp` уже есть — оставить, easing привести к `cubic-bezier(.22,1,.36,1)`.
- `--transition`: `all .2s cubic-bezier(.32,.72,0,1)`.
- Уважать `@media (prefers-reduced-motion: reduce)`.

## 4. Логотип — заменить SVG в splash

В `templates/base.html` сейчас старая геометрия логотипа. Замени `<svg>` внутри `.splash-logo` на **точный вордмарк «Концепция 1»** из `redesign/logo.js` → переменная `SHEF_LOGO`:

- viewBox `0 -18 720 236`; группа `.body` (тело) — белая на тёмном splash; `.accent` — **всегда `#2563EB`** (наконечник «Е», въезжает по 45°).
- Анимацию можно сохранить твою (stroke-draw + accentFlash) ИЛИ взять из редизайна: тело мягко «оседает», синий наконечник въезжает по 45°, размытый синий слэш на фоне. См. `<style id="splash">` в `ШЕФ - Редизайн.html`.
- Монограмма `SHEF_MONO` (одна «Ш» с синим вымпелом) — «лицо» ИИ: используй её как favicon и в шапке.

Правила: наклон акцента строго 45°; синий не перекрашивать; зона защиты ≥ высоте «Ш»; монограмма на тёмной скруглённой плашке.

> Файл `redesign/logo.js` отдаёт строки SVG (`window.SHEF_LOGO`, `window.SHEF_MONO`). Для Flask просто **вставь разметку SVG прямо в шаблон** (Jinja) или положи как `static/img/logo.svg` / `mono.svg`.

## 5. Новый `styles.css` — что в нём собрать

Сохраняя имена классов, привести компоненты к языку ШЕФ (точные стили — в `redesign/redesign.css` + `views.css`):

- **`.card`** — `--card-bg`, рамка `--border`, `--radius-lg (22px)`, `--shadow-md`; hover: `translateY(-3px)` + `--shadow-lg`.
- **`.card-grid`** — `minmax(345px,1fr)`, `gap: 16px`.
- **`.btn`** база `padding:10px 16px; radius:14px; font-weight:700`.
  - `.btn-primary` — синий **градиент** `#3B78F0→#2563EB→#1D4ED8`, `--sh-blue`, верхний глянец, hover `translateY(-1.5px)`, active `scale(.96)`.
  - `.btn-secondary` → стиль ghost: стекло (blur + полупрозрачный белый + рамка) **или** простой светлый — у ШЕФ это `.btn-ghost`.
  - `.btn-danger` — оставить красный, привести к `--red`.
  - добавить `.btn-sm`, `.btn-icon` (38×38) для иконочных кнопок вместо эмодзи.
- **`.badge`** → пилюли статусов: `Заполнено`→`pill-green` (с LED-точкой), `В работе`→`pill-amber`, `Не заполнено`→`pill-gray`, `Активен`→`pill-blue`. Радиус `--r-pill`, 12px/700.
- **`.form-input/.textarea/.select`** — рамка `--line-2`, focus: `border-color:--accent` + `box-shadow:0 0 0 4px --accent-weak`.
- **`.modal-card`** — `--radius-xl (26px)`, `--shadow-lg`; оверлей `rgba(20,21,26,.42)` + blur.
- **`.toast`** — можно оставить, привести радиус/тень к токенам.
- **`.page-title`** — Manrope 800, 28–34px, трекинг −.035em.
- **Мотив-утилиты** (добавить): `.diag-cut` (срез-угол 45° через `::after` border-triangle), `.shef-mono` (плашка монограммы + состояние `.thinking` со сканом), `.shef-byline`.

> Самый простой способ ничего не упустить — открыть `ШЕФ - Дизайн-система.html` рядом и сверять каждый компонент визуально.

## 6. Точечные правки шаблонов (после CSS)

> **Важно — почему часть страниц «не изменилась».** Новый `styles.css` меняет только
> **вид существующих классов** (кнопки, бейджи, формы, splash, модалка — преобразятся сразу).
> Но он **не может изменить разметку**: добавить аватар-срез, убрать эмодзи `✎ 🗑`,
> переставить элементы карточки. Это делается в самих шаблонах.
> `briefs_list.html` и `brief_form.html` уже используют классы статусов (`pill-*`) — они
> подхватят дизайн. А **`index.html` нужно заменить** — готовый файл лежит в
> `integration/templates/index.html` (вся Jinja-логика, `url_for`, `showDeleteModal`,
> пустое состояние сохранены). Просто скопируй его в `templates/index.html`.

### 6.1 `index.html` — карточка клиента
- Добавить **аватар-срез 45°** слева от имени: квадрат `48px`, `border-radius:14px; border-top-right-radius:3px`, диагональный градиент-фон, синий треугольник в углу (класс `.diag-cut` / `.big-av av-md`). Инициалы из `client.name`.
- Бейдж `Активен` → `class="badge pill-blue"` (или `.pill .pill-blue`).
- Заменить эмодзи `✎`/`🗑` на `.btn-icon` с line-иконками (edit/trash).
- Дату оставить в `--ink-3`.

### 6.2 `briefs_list.html` — статусы анкет
- Карточки 3 анкет — `.card` с hover-подъёмом.
- Статус-бейдж по `brief.status`:
  `Заполнено`→`pill-green`, `В работе`→`pill-amber`, `Не заполнено`→`pill-gray`.
- Если анкеты сгенерированы/проверены ИИ — пометить **ШЕФ-байлайном** (монограмма xs + «ШЕФ»).

### 6.3 `brief_form.html`
- Секции анкеты — в `.card`/`.section-card`, заголовки секций как `eyebrow`/`.sc-title`.
- Кнопки «Сохранить» / «Сохранить и завершить» — `.btn-ghost` и `.btn-primary`.
- Кнопка PDF — `.btn-secondary` с line-иконкой `doc`.
